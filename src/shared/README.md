# 共享模块

此目录存放主进程和渲染进程复用的纯逻辑和数据契约。文件按业务域归属，保留原有文件名，调用方直接引用具体模块。

| 目录 | 职责 |
| --- | --- |
| `ai/config` | 智能体默认 JSON、配置校验、角色与技能配置 |
| `ai/conversation` | 会话快照、上下文、候选、消息、错误和任务状态投影 |
| `ai/permissions` | 安装授权、确认预览与权限展示 |
| `ai/tools` | 工具协议、执行循环、日志及 `schemas` 下的参数定义 |
| `ai/installation` | 智能体安装决策、预检刷新、来源凭据和冲突计划契约 |
| `ai/readiness` | 就绪条件、状态计算与各类验收门禁定义 |
| `installation` | 安装规则声明、编译入口、文档契约、流程与失败恢复；编译实现位于 `compiler` |
| `sources` | 来源注册、网络策略、平台身份、目录和安装协议 |
| `modpacks` | 在线/离线整合包契约与实例差异 |
| `dlss-swapper` | DLSS 计划、版本、安装路径及专用语言资源 |
| `translation` | 来源内容翻译、模型配置与翻译运行策略 |
| `i18n` | 界面语言策略、原生提示、更新和 Trainer 共享文案 |
| `app` | 客户端发行配置、更新版本、统计策略与第三方清单 |
| `account` | 用户头像与用户配置策略 |
| `games` | 游戏库、公共规则支持与模组管理位置 |
| `tasks` | 安装任务中心展示策略与任务计数 |
| `downloads` | 下载引擎及并发配置 |
| `system` | 系统已安装应用的身份与卸载结果契约 |
| `ipc` | 跨进程能力和通道声明 |
| `utils` | 与业务无关的通用缓存工具 |

## 依赖边界

- 共享模块可以引用其他共享业务域的明确契约；避免双向依赖和循环，不按调用方进程复制实现。
- 文件系统、数据库、网络请求、窗口与进程操作留在相应进程或服务层。共享代码不导入 `main`、`renderer`、`preload`、Electron、Node 内置模块或 Vue 状态。
- 外部依赖须能在两端使用；当前仅使用 `crypto-js` 的摘要与编码模块。增加依赖时同时核验跨环境兼容性及边界检查。
- 新模块进入其业务域；内容 AI 翻译配置放在 `translation`，界面语言放在 `i18n`。不在根目录堆积实现，不建立全局 `index.js`，不保留旧路径转发层。
- 安装规则的能力入口为 `installation/install-rule-declarations.js`，公共说明为 `installation/install-rule-documentation.js`，编译入口为 `installation/install-rule-compiler.js`。实际规则正文仍在渲染端现有技术参考与用户指南。

修改共享模块时核对主进程与渲染进程调用方，运行代码检查和构建，并按变更范围验证实际功能与错误路径。
